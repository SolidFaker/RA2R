# 《红色警戒2：尤里的复仇》现代引擎复刻 — 项目规划与里程碑

> 文档状态：v0.1（规划稿）· 文档语言：中文 · 代码标识符：英文
> 配套文档：[docs/REFERENCE.md](REFERENCE.md)（社区资源与格式索引）

---

## 1. 项目定位

以《尤里的复仇》（YR 1.001）为行为与观感基准，**只复用原版美术与建模素材**（SHP / VXL / 调色板 / CSF 文本），引擎代码全部自研重写，用现代图形学与工程实践重新实现一款完全复刻。

- **做**：玩法、数据（rulesmd/artmd/aimd/地图/战役）、观感与原版一致；GPU 渲染、高 DPI、确定性模拟、可测试、可扩展（为后续 mod 与新功能留口子）。
- **不做**：反汇编 `gamemd.exe`；与原版联机互通；分发任何 EA 素材；支持 RA2 1.0（以 YR 为唯一基准）。

**现状盘点**：工作区已有一份完整 YR 安装（`Yuri/`，约 1.1 GB）：`ra2.mix` / `ra2md.mix`（加密）、`language.mix` / `langmd.mix`、`multimd.mix`、`thememd.mix`、`movmd03.mix`（视频，394 MB）、`mapsmd03.mix`、`ra2.csf` / `ra2md.csf`，以及官方 + 大量玩家自制 `.yrm/.yro/.mmx` 地图——M0 可行性验证可立即开工。

**重要事实**：EA 2025 年 GPL 开源的 C&C 源码为 Tiberian Dawn / Red Alert / Renegade / Generals: Zero Hour，**不含 RA2/YR**，因此本项目的自研复刻前提成立且不可替代。

## 2. 已确认决策

| 决策项 | 结论 |
| --- | --- |
| 技术栈 | 自研 **C++20** 引擎（CMake + vcpkg） |
| 首发平台 | **Windows 优先**，架构预留跨平台 |
| 推进主线 | **单机优先**（遭遇战 + 战役闭环），联机最后；确定性按联机标准从第一天设计 |
| 语言 | 中文文档 + 英文代码标识符 |

## 3. 开放决策点

| 编号 | 议题 | 选项与建议 |
| --- | --- | --- |
| D1 | 代码许可 | A) **MIT + 洁净室**：只读文档/规格，代码全自写（符合"只使用素材"原意，M0/M1 较慢）；B) **GPLv3**：可吸收 Chronoshift/Phobos 等社区解析代码，大幅加速，但项目不可闭源。**建议先按 A 推进，遇格式阻塞再评估转 B。** |

| D3 | 资产定位 | 运行时由用户指定 YR 安装目录（默认尝试本机 `Yuri/` 路径）；**素材永不入库**，见 §9。 |

## 4. 总体架构

```
┌─────────────────────────────────────────────────────────────────┐
│ Game（装配层：游戏流程/战役/遭遇战 UI）                             │
├──────────────────────┬──────────────────────────────────────────┤
│ Sim（15Hz 确定性）      │ Render（60/120Hz，逻辑插值）               │
│  · ECS（EnTT）         │  · 等距画家排序（cell+subcell+z-adjust）    │
│  · INI 规则库（全键建模）│  · GPU 精灵：调色板 LUT shader + 阵营重映射   │
│  · 寻路（A* + 组流场）   │  · 体素：VXL 网格化 + 法线光照 + 炮塔/HVA     │
│  · AI / 触发器 / 超武    │  · 迷雾/黑幕、小地图、后处理（默认关）        │
├──────────────────────┴──────────────────────────────────────────┤
│ Asset：MIX 解包 → 规范缓存（SHP 图集 / 体素网格 / INI 数据库 / CSF） │
├─────────────────────────────────────────────────────────────────┤
│ Platform：SDL3（窗口/输入/音频）· Net：锁定步（M8）· 工具：ImGui     │
└─────────────────────────────────────────────────────────────────┘
```

**确定性纪律（从 M0 第一天起执行，为 M8 联机铺路）**

- 逻辑帧固定 **15Hz**（与原版一致），渲染帧率解耦、状态插值；
- 模拟层只用整数/定点运算，禁止浮点与哈希无序容器；
- 稳定排序、固定遍历顺序、固定种子随机数；
- 存档/回放 = 模拟状态/输入流序列化，全部走确定性通道。

### M0 可行性验证与格式规格固化（2–3 周）

- 解密 `ra2.mix` / `ra2md.mix`（Blowfish 密钥），枚举并解包条目；
- SHP 解码（LCW/Format80 压缩）并渲染一个单位动画 + 阵营重映射；
- VXL 软件光栅化渲染一个车辆（验证法线与灯光模型）；
- 解析 `rulesmd.ini` / `artmd.ini` 核心节（步兵/载具/建筑/武器/弹头）；
- 解析一张 `.yrm`（IsoMapPack5）并渲染 temperat 地形一角；
- 产出：`docs/formats/*.md` 格式规格（以实测为准），PoC 小工具；
- **验收**：同地图同视角与原版截图并排对比肉眼一致。

### M1 资产管线与工具（3–4 周）

- 格式全覆盖：MIX（明文+加密变体）、SHP 全压缩变体、TMP/地形瓦片、VXL+HVA、PAL+光照等级、CSF、AUD/WAV、FNT、INI 全家（rulesmd/artmd/aimd/soundmd/thememd/evamd/battlemd/keyboardmd）、地图全家（`.map/.yrm/.yro/.mmx`）、BIK 视频（FFmpeg 解码，可选）；
- 工具：`tools/mixview` 资源浏览器（浏览/预览/导出）、`tools/assetcheck` 批量校验器；
- 规范缓存设计：SHP → RGBA 图集 + 帧元数据；VXL → 网格；INI → 编译规则库；地图 → cooked 格式，支持流式加载；
- **验收**：四个主 MIX 全量解包零报错；校验输出与 XCC 结果对照一致。

## 9. 法律与素材策略

- 本仓库**不包含任何 EA 素材**：`Yuri/` 目录与所有解包产物均列入 `.gitignore`；
- 运行时要求玩家自持正版 YR 拷贝并指定安装路径，引擎按需读取素材；
- 引擎代码许可见 D1；若吸收 GPL 社区代码，则项目整体转 GPLv3；
- 格式解析基于社区公开文档/规格与实测，不复制他人代码（洁净室）。
